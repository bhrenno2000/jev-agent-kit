Review this implementation against the keyed asynchronous cache contract and fix only evidenced contract violations while preserving compliant behavior. Scope and key are valid nonempty strings. TTL is a nonnegative integer, including zero. Loader is a function. An optional clock must provide a function returning a finite number. A cache entry is addressed by the ordered pair (scope, key). A successful load stores its value until the inclusive expiry boundary: a read at time expiresAt must reload, while a read before expiresAt may use the value. Expiry is measured from the clock reading taken after the loader resolves. Concurrent reads for the same pair while no valid entry exists must share one loader promise. A rejected loader, including a synchronous loader throw, must reject all waiters for that attempt, remove its in-flight state, and allow the next read to retry. Different scopes must never share entries or in-flight loads, even when their keys match or contain delimiter characters. `clear` removes only the fulfilled entry for its pair and does not cancel an in-flight load. `size` counts physically stored fulfilled entries. Expiration alone does not remove them; successful reload replaces them and clear removes them. Keep the public API and tests passing.
