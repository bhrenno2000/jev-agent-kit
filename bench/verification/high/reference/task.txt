Review and fix only evidenced contract violations in a partitioned event ingestion service. Preserve the public API and pass the public tests. The service must process independent partitions, deduplicate retries by partition and event identity, set each partition checkpoint to the maximum accepted offset even when a batch is out of order, publish one outbox record per accepted event, and commit each batch atomically. Concurrent overlapping and independent batches must not lose accepted events or checkpoints. A failed persistence operation must leave events, checkpoints, deduplication state, and outbox unchanged, and the same batch must be retryable after the fault. Empty batches and invalid events must reject without mutation. Returned snapshots, outbox records, and stored payloads must not alias caller-owned objects. Event and partition identifiers are arbitrary nonempty strings and may contain colons and NUL characters. An exact partition-and-id retry is deduplicated even if its payload or offset differs; identity fields define the duplicate. Initial checkpoints, when supplied, are a plain object from nonempty partition strings to nonnegative integer offsets. Keep the implementation dependency-free and run the test suite.
